# Limitations

* **Single vintage.** Revisions between releases cannot be observed from one file; no reporting
  triangle is built or imputed. The earlier 5/108 result remains unverified.
* **Later file is not truth.** Any future comparison uses a later WHO file as the reference;
  later files can still be revised.
* **Notifications are not incidence.** Declines can reflect reporting, programme, access or
  definitional changes; no causal attribution (COVID-19, funding) is made.
* **Shrinking, selective coverage.** Complete H1 fell from 117 countries (2021) to 67 (2025), and
  strict same-definition pairs from 53 to 32; reporting countries are not a random sample.
* **Maturity.** At 109 days after H1 2026 ended, no country had a complete H1 2026 in the WHO file,
  which argues against an "immediate early warning" framing.
* **Dependence.** Up to 5 year pairs per country; the balanced panel has only 10 countries, so
  bootstrap intervals there are descriptive.
* **Definitions.** Coverage code (all/some units) changes and monthly/quarterly switches exclude
  many pairs; the 50-case floor and zero-cell rule are judgement calls, with a relaxed sensitivity tier.
* **Defer rule buffer** (0.03) came from earlier in-sample exploration; it is fixed, not validated.
* **Public-by dates** prove existence by our access time only.
